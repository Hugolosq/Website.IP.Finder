# Website.IP.Finder
A simple but useful Command-Line Interface (CLI) tool written in Python.

## Features
* Resolves a website domain to its IP address using `socket`.
* Fetches approximate geolocation data (Country, Region, City, Coordinates) using the `ip-api.com` API.
* Provides a direct Google Maps link to the location.
* Colourful and user-friendly terminal interface.

## Prerequisites
* [Python 3.x](https://www.python.org/downloads/) installed on your system.
* [Git](https://git-scm.com/downloads) installed on your system.

## Installation
1. Clone this repository or download the files:
```bash
git clone https://github.com/Hugisso/Website.IP.Finder.git
```
2. Install the required dependencies:
```bash
pip install -r requirements.txt
```
## Usage
You can run the tool simply just clicking on the .py file or running this command in terminal:

```bash
python Website.IP.Finder-v3.0.3.py
```
To exit the program while it's running, simply type **`exit`** or **`q`** and press Enter.
